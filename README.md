# HR Analytics Dashboard

## 📌 Overview
This project is an interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, salary, age distribution, recruitment sources, and departmental performance.

## 🛠 Tools Used
- Power BI
- Power Query
- DAX

## 📊 KPIs
- Headcount
- Attrition
- Attrition %
- Average Salary
- Average Age

## 📈 Dashboard Features
- Department-wise Headcount
- Headcount by Age Group
- Headcount by Marital Status & Gender
- Recruitment Source Analysis
- Yearly Attrition Trend
- Interactive Filters

## 💡 Business Insights
- Production department has the highest headcount.
- Employees aged 36–45 make up the largest workforce group.
- LinkedIn is one of the major recruitment sources.
- Attrition rate is 33.44%.
- Average employee salary is 69.02K.
